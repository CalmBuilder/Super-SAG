# 00 基线与目标

Super-SAG 使用独立版本序列，当前初始化候选版本为 `v0.1.0`。桌面版保持本地单用户、无需登录，原文件保留在原目录；知识库、索引、搜索、问答、文件操作、设置和 CLI 逐项验收。

1. 先完成 Windows 和 macOS 个人桌面版的打包、安装、运行、业务和数据保留验证。两者均无需登录和租户选择；macOS 覆盖 Apple 芯片与 Intel，并区分原生系统、虚拟环境和真实用户设备的验证证据。
2. 两个桌面平台完成约定验收并冻结 Windows 界面基准后，使用相同输入、语言、主题和视口，在真实浏览器逐屏还原 Web 的样式和交互。
3. 接通 Linux 服务器上经授权的目录、文件、索引、搜索、问答和设置，保持桌面业务语义。
4. 最后增加多用户、多租户及知识库授权；租户、目录、索引、配置和用户会话必须隔离。
5. 新 Web 入口采用 `app.sh` 并监听 `0.0.0.0:8167`；旧 Web 原型仅借鉴设计和测试经验。

Web 部署能力是企业化的基础，多用户、多租户、授权隔离和运维验收完成后才能确认企业需求已满足。每一阶段均记录正常、极值、边界和失败结果；涉及 Web 时还须真实浏览器回归，涉及桌面共享代码时须在 Windows 与 macOS 回归。开发夹具、静态截图和编译成功均不能替代业务验收。
