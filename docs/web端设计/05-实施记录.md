- 产品范围调整为 Windows 和 macOS 同等支持的本地免登录个人版；两者验收之后，以 Windows 为界面基准，先完成 Web 样式及交互，再接通真实业务，最后增加用户、租户及授权隔离。旧 Web 代码和数据库不迁入。
- 在提交 `5e30e3e`（基于桌面代码 `9459f4b`）的临时验证分支启动 [macOS 原生环境构建](https://github.com/CalmBuilder/Super-SAG/actions/runs/42955911704)，Apple 芯片和 Intel 的构建、DMG 隔离复制与启动及随包 CLI 检查均通过，详见[范围与证据](验收证据/24-macOS原生构建检查.md)。本轮桌面包早于 Safari 标题修正且未包含 Safari 扩展，后续提交须重新构建核验。macOS 虚拟机不是物理设备，启动检查不能代替窗口交互、真实模型、旧数据升级和签名分发验收。
- 本地 `npm run check` 和 `npm --prefix docs-site run build` 通过；文档站构建报告两条 CSS `::highlight` 优化告警。检查了中英文安装、更新、开发页面、已发布版本链接及 `macOS` 搜索结果；安装页面还使用本机无头 Chromium 加载。
- 本地 Linux 运行 `tests/cli-guide-e2e.py` 通过，覆盖真实临时文件索引、目录增删和 Agent 安装等；Jev 使用本地协议替身，此结果不代表 macOS 或真实模型通过。
- macOS Safari 扩展复核发现中文引导标题仍使用旧品牌，已改为 Super-SAG；本地两组 Safari 引导 Vitest 共 6 项和真实 Chromium 的中英文切换、模拟原生按钮检查通过。修正后的开发包已在 Apple 芯片和 Intel 的 macOS 15 重新构建并检查包内标题；实际 Safari 安装启用与原生窗口交互仍待验证。
- 根据用户请求构建 `v0.1.0` 两种芯片的 macOS 测试安装包，构建、CLI 和主窗口验证范围及签名限制见[测试包记录](验收证据/25-macOS-0.1.0测试安装包.md)。测试包未加入正式 Release；正式签名、公证和完整业务仍待验收。
