# 07 审核与风险

- **产品：**Windows 桌面免登录并保留文件与现有操作习惯；Web 先视觉与交互、后业务、最后租户。
- **安装与兼容：**版本序列重置后，不能按显示版本大小推测可安全升级；安装器、CLI、服务和真实用户数据均需独立核验。
- **数据与安全：**保留真实文件、旧路径及用户设置；任何修改、取消和失败都不得静默删除数据。
- **Web：**现有预览只是测试夹具，未接入真实后端；服务器目录应显式授权，浏览器不可透传任意本机命令。
- **权限：**成员、租户和知识库授权分层；平台身份不自动赋予跨租户内容读取权。
- **验收：**必须区分静态测试、模拟模型、真实浏览器、云 Windows 和用户实机；任何未通过或未执行项目保持待验收状态。
