# 09 品牌与兼容

| 范围 | 要求 |
| --- | --- |
| 产品显示 | 桌面名称、图标、关于、安装与卸载入口显示 Super-SAG。 |
| 新数据 | 新建默认目录使用当前产品名称，原文件留在用户选择的位置。 |
| 旧数据 | 保留既有真实路径、受管理 CLI、Skill 和本地接口兼容；不改名、移动或删除用户文件。 |
| 构建与服务 | 桌面与 CLI 版本一致；构建身份明确，未知较新版本不得被静默覆盖。 |
| 更新 | 无独立签名渠道前不检查或安装更新，不伪造已发布下载地址。 |
| 验收 | 以真实 Windows 应用、实际文件、服务和配置为准；测试截图使用虚构数据。 |
