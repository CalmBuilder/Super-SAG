# 01 Windows 品牌与数据兼容

桌面应用保持 Super-SAG 名称和标识，当前安装包版本为 `v0.1.0`。应用、CLI 和服务共享本地数据；已有文件、知识库、索引、设置、会话和笔记必须保留。

- 保留必要的历史目录、安装注册身份、CLI 命令、数据格式和快捷方式兼容；不为展示名称移动或删除原文件。
- 本次版本序列重置后，已识别的测试构建只能按明确身份迁移；不能把任意较新版本当作旧版本覆盖。
- 安装器、CLI 与后台服务分别验证版本和构建标识；运行中的旧服务应安全停止或明确报错。
- 在隔离 Windows 环境用可恢复的测试数据检验安装、重启与升级。取消安装、缺少权限、占用文件、未知较新版本及中断恢复也要覆盖。
- 独立签名和自动更新渠道尚未配置；不得发布或启用未经验证的更新地址。

实际 Windows 操作和证据要求见[构建与实机验收](08-Windows构建与实机验收.md)。
