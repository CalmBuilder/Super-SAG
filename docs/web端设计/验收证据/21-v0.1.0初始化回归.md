# v0.1.0 初始化回归记录

日期：2026-11-11。下列为初始化候选在 Linux 工作区的实际结果，不能代替用户 Windows 实机验收。

- `npm run check`：0 错误、0 警告。
- `npm run build`：通过；Vite 对大于 500 kB 的打包片段给出体积提示。
- `npm test`：93 个文件、702 项通过，包括桌面与浏览器扩展图标一致性；DOM 测试环境输出了不支持外部脚本、iframe 和 canvas 的提示。
- `cargo test --locked --manifest-path protocol/Cargo.toml`：10 项通过，覆盖已识别旧测试版与 `0.1.0` 的排序、未知构建和异常版本。
- `cargo test --locked --manifest-path client/Cargo.toml`：7 项通过，使用服务测试替身检查版本兼容。
- `RUST_TEST_THREADS=1 cargo test --locked --manifest-path cli/Cargo.toml --test install --test commands --test onboarding`：41 项通过。首次以默认并发执行时，多个临时 CLI 副本耗尽可用空间，11 项失败；改为单线程后全部通过。
- 使用 release 构建类型执行 `cargo test --locked --release --manifest-path cli/Cargo.toml --test bootstrap`：8 项通过；为缩短本机编译时间关闭了优化和 LTO。旧版安装记录是夹具，不是用户机器的实际文件。
- `python tests/cli-guide-e2e.py --binary cli/target/release/sag`：隔离 Linux 用户目录中执行 CLI 安装、三个 Agent Skill 安装、配置、加入、索引、搜索、移除与恢复、服务重启及异常范围；验证源文件未改变。检索判断使用本机 Jev 协议夹具，不是实际模型或实际 Agent 客户端。
- `node --test scripts/check-windows-template.node-test.mjs`：1 项通过，检查模板预检和变更检测；不能证明 NSIS 已打包。
- 真实 Chromium 156：桌面品牌 8 组、品牌补全 9 组；网页剪藏扩展在隔离浏览器存储中检查首次使用、旧目录保留、新目录保存与空内容失败；未调用 Windows 系统选择器。
- 真实 Chromium 视觉对照：桌面和窄屏多视口、交互、边界及失败情形通过；数据、文件、模型及 Web 接口为测试替身，不代表业务和 Web 产品验收。
- `npm --prefix docs-site run build`：构建通过；CSS 优化器对依赖提供的 `::highlight` 输出两条提示。真实 Chromium 检查中英文共 22 个页面、32 张页面图片、38 个内部链接和两种语言的文档搜索，无页面脚本错误。

Windows 安装器的云端构建结果以 GitHub Actions 运行记录为准。用户现有 Windows 安装、真实旧文件、索引、配置与会话的覆盖升级，以及真实模型搜索、问答和 Agent 客户端均未在本轮完成验收，不标记通过。
