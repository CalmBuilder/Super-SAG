# CLI and Agent integration

The Windows installer includes the Super-SAG CLI. After the desktop application initializes it, open a new terminal and run `super-sag --version`. Use `super-sag install claude-code`, `super-sag install codex` or `super-sag install opencode` to install the corresponding Skill.

The complete [CLI reference](../../docs-site/content/docs/cli.en.mdx) documents commands, configuration, indexed folders and removal behavior. No standalone npm package has been published.
