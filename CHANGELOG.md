# 更新日志 / Changelog

## 0.1.0

- **首次发布**：提供 Super-SAG 桌面、CLI 与网页访问，支持文档索引、搜索和模型问答。Windows x64 安装包未签名；macOS Apple Silicon / Intel 测试包仅使用临时签名，未经公证。分享码和文档组件在线下载暂不可用。

### English

- **Initial release**: Super-SAG provides desktop, CLI and browser access for document indexing, search and model-assisted answers. The Windows x64 installer is unsigned; the macOS Apple Silicon and Intel test builds are ad-hoc signed and not notarized. Share codes and online document-component downloads are not currently available.
