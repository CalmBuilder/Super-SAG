## Desktop

The initial `0.1.0` source is a local candidate and has not been released.

After the new candidate is built and validated on its target platform, use its corresponding installer. A macOS test package without formal signing and notarization is not a formally signed release.

## CLI only

A standalone Super-SAG npm package has not been published. The desktop app can initialize its bundled CLI; developers can also follow the [development guide](/en/docs/development) to build from source. After initialization, open a new terminal and run:

```sh
super-sag --version
```

## Updates

An independent signed update channel has not been configured. Download only published installers. The CLI and desktop app share settings and the knowledge base.
