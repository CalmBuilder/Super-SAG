## Windows desktop app

The Super-SAG Windows installer is in preparation and has not been published or accepted on a Windows machine. There is currently no official Super-SAG download. See the [development guide](/en/docs/development) for source-build preparation.

The installer includes the local CLI. After the desktop app initializes it, open a new terminal and run `sag --version`. The CLI and desktop app share the local knowledge base, settings and service, with no login required.

<Callout title="Upgrading from the original">An in-place upgrade from SAG-Wiki still requires acceptance on Windows with the original installer and isolated test data. Do not overwrite your only copy of production data before that verification.</Callout>

## About and updates

Open **Settings → About** to see the Super-SAG version and attribution to the upstream SAG-Wiki project and development team.

![Super-SAG About page and update status](/images/product-about-en.png)

This image uses synthetic data and a browser test fixture; it is not evidence of Windows installation acceptance.

This build does not yet have an independently signed Super-SAG update channel, so it does not check for, download or install updates. Previous settings are retained, but their upstream update source is not enabled. A release and download path will be provided once the independent signing channel is ready.

## CLI and agents

A standalone Super-SAG npm package has not been published. The desktop installer contains the CLI, which the app can initialize. The upstream npm package is a separate distribution. Continue with [Agent integration](/en/docs/agents) and the [CLI reference](/en/docs/cli).
