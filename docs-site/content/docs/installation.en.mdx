## Windows desktop app

The current version is `v0.1.0`; a [Windows installer is published](https://github.com/CalmBuilder/Super-SAG/releases/tag/v0.1.0). The user reports that Windows business workflows and a data-preserving upgrade passed on their machine; the tested package and source are listed in the [acceptance records](https://github.com/CalmBuilder/Super-SAG/tree/main/docs/web端设计). See the [development guide](/en/docs/development) for source-build preparation.

The installer includes the local CLI. After the desktop app initializes it, open a new terminal and run `super-sag --version`. The CLI and desktop app share the local knowledge base, settings and service, with no login required.

<Callout title="Upgrading existing data">The user reports a successful data-preserving upgrade; verify other installation and data environments separately. Back up first; selecting “delete application data” in an uninstaller affects settings, indexes and conversations.</Callout>

The `v0.1.0` installer allows an in-place upgrade only for the specifically identified test build. Unrecognized versions and MSI installations matching this product identity are stopped, leaving the existing installation in place. Silent same-version reinstalls are also stopped; an interactive reinstall requires an explicit choice. If the installed version cannot be verified, keep the installation and data in place and check the version and backups first.

## macOS desktop app

The macOS personal edition targets Apple silicon and Intel. Build, installation and business acceptance are in progress, and no macOS installer has been published. The desktop app requires neither login nor tenant selection. See the [acceptance records](https://github.com/CalmBuilder/Super-SAG/tree/main/docs/web端设计) for verified scope.

## About and updates

Open **Settings → About** to see the Super-SAG version and update status.

![Super-SAG About page and update status](/images/product-about-en.png)

This image uses synthetic data and a browser test fixture; it is not evidence of Windows installation acceptance.

This build does not yet have an independently signed Super-SAG update channel, so it does not check for, download or install updates. Previous settings are retained, but old update sources are not enabled. Installers are available from published releases; in-app updates require an independent signing channel.

## CLI and agents

A standalone Super-SAG npm package has not been published. The desktop installer contains the CLI, which the app can initialize. Continue with [Agent integration](/en/docs/agents) and the [CLI reference](/en/docs/cli).
