## Desktop

Download the installer for your platform from [Super-SAG v0.1.0](https://github.com/CalmBuilder/Super-SAG/releases/tag/v0.1.0):

- **Windows x64**: the installer is unsigned, so Windows may display an unknown publisher warning.
- **macOS Apple Silicon / Intel test builds**: open the appropriate DMG and drag `Super-SAG.app` into **Applications**. These builds are ad-hoc signed, without Apple Developer ID signing or notarization; macOS Gatekeeper rejects them by default. Use them only in a test environment if you accept this limitation; see [Apple's guidance](https://support.apple.com/en-us/102445) for available options.

## CLI only

A standalone Super-SAG npm package has not been published. The desktop app can initialize its bundled CLI; developers can also follow the [development guide](/en/docs/development) to build from source. After initialization, open a new terminal and run:

```sh
super-sag --version
```

## Updates

An independent signed update channel has not been configured. Download only published installers. The CLI and desktop app share settings and the knowledge base.
