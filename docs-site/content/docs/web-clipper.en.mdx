title: Web Clipper
description: Save webpages as local Markdown independently, with optional Super-SAG indexing.

The extension saves the current webpage's main content as a local Markdown file. It does not require a connection code, a running Super-SAG app, Obsidian, or a model.

The Windows build is configured to include the Chrome / Edge extension ZIP, pending Windows acceptance. No Super-SAG extension or verified Safari installer has been published.
The Safari development setup page is titled **Super-SAG Web Clipper**; actual installation, enablement and clipping still need validation.

## Install

1. Click the globe icon for **Web Clipper** at the top right of Super-SAG and download the package for your browser. You can also open it through **Settings → Web Clipper**. Hover over the icon to see its name.
2. Install and enable the extension.
3. Right-click a webpage and choose **Save as Markdown** to open a preview.
4. Review the title, content and destination, then click **Save** to create the file. **Cancel** or closing the window does not save it.

![Web Clipper and Connect Agent icons at the top right](/images/web-clipper-entry-en.png)

The desktop build prepares the Chrome / Edge extension for installation in Developer mode. Safari instructions are retained as a reference for later verification.

- **Chrome / Edge (Windows / macOS)**: extract the ZIP, enable **Developer mode** in extension management, select **Load unpacked**, and choose the extracted folder.
- **Safari (macOS)**: open the notarized DMG, drag `Super-SAG Web Clipper.app` onto the **Applications** folder beside it, then open the copied app from Applications and enable it in **Safari Settings → Extensions**. The DMG provides a drag-and-drop installation window; you still complete the copy and enable the extension. The notarized package does not require **Allow Unsigned Extensions**. Unsigned builds made from source still require that developer setting.

The Safari app shows a language selector and **Installed · enabled** or **Installed · not enabled**. When enabled, click **Done** to close the window and return to a webpage. Otherwise, use **Quit and open Safari settings** to enable the extension. Settings remain available while checking. If Safari has not returned a result after 8 seconds, the app shows a message and **Check again**, rather than leaving the button locked. Returning to the app refreshes its status. If Safari has not detected the extension, the app reports that condition instead of showing Done.




Download buttons export packages included in the current desktop build. A browser's button is unavailable if its package is absent.

## Preview and save

Safari shows a small Super-SAG icon beside **Save as Markdown**. The context menu opens a separate preview window showing the page title, source URL, Markdown and destination before writing a file. Its initial size is 520 × 660 and it opens centered over the browser window containing the source page, with longer content scrolling inside the preview. Click **Save** to save the previewed content. Switching or closing the original page after the preview loads does not change that content.

The toolbar clipping feature and its settings switch have been removed. Use the webpage context menu. Installation and updates do not change Safari’s address bar or toolbar layout, and the extension does not need to be pinned to the toolbar. Browsers may retain their own extension-management icon: in Safari, right-click it and choose **Remove from Toolbar**; in Chrome / Edge, unpin it through the extensions menu.


## Save folder

On first initialization, Super-SAG creates `Documents/super-sag/clippings` and adds `Documents/super-sag` to folder management. Existing libraries are not changed. Use **Add clipping folder** to add it manually when needed.

**Save to** initially selects **Default folder (Documents/super-sag/clippings)**. Safari can save there as soon as the extension is installed and enabled; no folder selection or Save settings step is needed. The directory is created if missing. macOS may display its own Documents access prompt. The preview shows the actual full path.

Chrome / Edge use the browser folder picker: choose the system Documents folder on the first **Save**, then subsequent saves use `super-sag/clippings` directly. Cancelling keeps the preview open without creating a file.

To use a different location, select **Choose another folder**, click **Choose folder**, then click **Save settings**. The dropdown shows **Custom folder (location)** directly. Default and custom folders are stored separately, and unsaved changes do not affect actual saves. The indexing reminder appears only after applying a changed destination; reopening settings or choosing the same folder does not repeat it.

Safari shows the full selected path in the dropdown. Chrome / Edge expose the selected folder's name, and the default location shows its known relative path. Use **Choose folder** or **Change folder** and click **Save settings** to select the location again when needed. Safari remembers the selected folder in the native component included with the extension, without connecting to Super-SAG.

On Windows, the default `super-sag\clippings` folder is created inside the system Documents folder. Use the directory picker to authorize locations on other drives or with non-ASCII characters and spaces. The Windows desktop package includes the Chrome / Edge extension. Packaging configuration and filename rules have been checked; saving on a Windows machine has not yet been verified.

An optional **Downloads folder** mode remains available: Chrome / Edge use the browser's download directory and optionally a Save dialog for each file; Safari uses system Downloads. This mode defaults to the `clippings` subfolder and accepts other relative subfolders or an empty value.

The clipping window shows save status and the actual saved path. Chrome / Edge show a pending state until the download finishes and report interrupted downloads as errors.

Each save creates a separate `.md` file with its title, source URL, capture time, and content, without overwriting existing files. Images keep their original URLs and may be unavailable offline. Browser internal pages and PDF extraction are outside the current scope.

## Add to knowledge base (optional)

Click **Add clipping folder** in Super-SAG's Web Clipper settings and choose the actual save folder, or add it through the existing folder manager.

Super-SAG then updates the index according to file-type, exclusion and **Watch file changes** settings. Add a new folder separately after changing the extension destination; older files are not moved. The extension can save while Super-SAG is closed. Indexing updates when the background service runs and checks the folder.

## Language and data

The extension interface, context menu, and common save errors support Simplified Chinese and English. It follows the browser language by default, with a language selector in extension settings. The Safari setup app also offers both languages. System file dialogs use the system language.

The interface uses black, white, and gray in both system light and dark modes. Settings use 18px text and buttons with a 26px heading. Context-menu, preview, settings, package, and Safari application icons all have transparent backgrounds. Icons have dedicated small-size images, and the Safari application icon has a larger symbol. Buttons, inputs, selected controls, and error messages share the same palette.

Content extraction is local. The extension does not use a local HTTP port, a connection code, or a model service. Safari's native saving component only receives requests from its own extension and limits writes to the default `Documents/super-sag`, a user-selected folder or system Downloads. Later searches and questions in Super-SAG follow existing model settings.


Upgrades retain existing default folders without moving files. The sidebar displays Super-SAG; hover to see the actual path. Previously authorized clipping folders remain in use when the extension ID stays the same; after reinstalling or changing the ID, select the old folder again.


The Super-SAG Safari extension still requires its own build, notarization and real macOS acceptance; the Windows installer does not include it.
