---
title: "File sharing"
description: "Share codes and web access."
---

Creating, receiving, and cancelling share codes is temporarily unavailable because no share-code service is configured. Files and the knowledge base remain available.

To access the same knowledge base on a local network, enable the [web service](/en/docs/remote-access) on the host and connect to its actual IP address and port. Web access and share codes are separate features.
