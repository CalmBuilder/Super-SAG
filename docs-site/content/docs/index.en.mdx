## Start with your local files

![Desktop interface with synthetic test data](/images/product-ask-home-en.png)

These examples use synthetic test data; actual Windows behavior requires hands-on acceptance.

Super-SAG reads the folders you add and keeps original files in place. The desktop app and CLI share one local service, index and configuration. The CLI remains available after the desktop app closes.

## Choose your workflow

| Task | Start here | Requirements |
| --- | --- | --- |
| Find words, files and source passages | [Search](/en/docs/search) | Add a folder; no model key needed |
| Find evidence for a question across documents | [Deep search](/en/docs/search#deep-search) | Configure Jev |
| Generate an answer with citations | [Q&A](/en/docs/chat) | An answer model; Jev for semantic retrieval |
| Let an agent search your project | [Agent integration](/en/docs/agents) | CLI, Skill and Jev configuration |

## Fast indexing, original sources

Indexing requires no LLM or embedding model. Actual time varies with hardware, file count, format and conversion work.

Search results keep source locations. Answer citations open the full document, scroll to the relevant passage and highlight it.

<Callout title="Your data">Original files stay local. Deep search and Q&A send the required question, passages or context to your configured services. Local quick search does not need a network model.</Callout>
