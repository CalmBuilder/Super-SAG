## Windows 桌面版

Super-SAG Windows 安装包正在准备，尚未发布或完成 Windows 实机验收。当前没有 Super-SAG 正式版下载链接。源码构建的准备步骤见[开发指南](/zh/docs/development)。

安装程序随附本地 CLI。完成桌面端的 CLI 初始化后，在新终端运行 `sag --version`。CLI 和桌面版共用本地知识库、配置和服务，无需登录。

<Callout title="原版用户升级">Super-SAG 的覆盖升级仍待使用原版 SAG-Wiki 安装和隔离测试数据在 Windows 实机验收。在验收通过前，请勿覆盖唯一一份业务数据。</Callout>

## 关于与更新

入口：**设置 → 关于**。这里显示 Super-SAG 版本，以及对 SAG-Wiki 上游项目和开发团队的署名。

![Super-SAG 关于页面与更新状态](/images/product-about-cn.png)

上图使用虚构数据和浏览器测试替身拍摄，不代表 Windows 安装验收结果。

当前构建尚未配置 Super-SAG 独立签名更新通道，因此不会检查、下载或安装更新。旧版配置会保留，但不会启用其上游更新源。正式更新方式和下载入口将在独立发布与签名链就绪后提供。

## CLI 与 Agent

当前尚未发布独立的 Super-SAG npm 包。桌面安装包内的 CLI 可通过桌面初始化安装；不要把上游 npm 包当成 Super-SAG 的发行包。继续阅读 [Agent 接入](/zh/docs/agents)和 [CLI 命令](/zh/docs/cli)。
