## 桌面端

从 [Super-SAG v0.1.0](https://github.com/CalmBuilder/Super-SAG/releases/tag/v0.1.0) 下载对应平台的安装包：

- **Windows x64**：安装包未经代码签名，Windows 可能显示发布者未知等提示。
- **macOS Apple Silicon / Intel 测试包**：打开对应的 DMG，将 `Super-SAG.app` 拖入 **Applications** 文件夹。测试包仅使用 ad-hoc 临时签名，未经 Apple Developer ID 签名或公证；macOS Gatekeeper 默认会拒绝打开。仅在了解此限制的测试环境中使用，相关选项见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 只安装 CLI

当前未发布独立的 Super-SAG npm 包。桌面端可初始化随附 CLI；开发者也可参阅[开发指南](/zh/docs/development)从源码构建。初始化后在新终端运行：

```sh
super-sag --version
```

## 更新

本项目独立签名更新通道尚未配置。安装包下载只使用已发布版本；CLI 与桌面共享配置及知识库。
