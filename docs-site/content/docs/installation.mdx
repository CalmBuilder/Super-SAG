## 桌面端

初始版本 `0.1.0` 目前是本地候选，尚未发布。

新候选完成构建和实机验证后，使用对应平台的安装包安装。macOS 测试包若未正式签名和公证，不能视为正式签名包。

## 只安装 CLI

当前未发布独立的 Super-SAG npm 包。桌面端可初始化随附 CLI；开发者也可参阅[开发指南](/zh/docs/development)从源码构建。初始化后在新终端运行：

```sh
super-sag --version
```

## 更新

本项目独立签名更新通道尚未配置。安装包下载只使用已发布版本；CLI 与桌面共享配置及知识库。
