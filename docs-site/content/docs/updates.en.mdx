## v0.1.0

The initial Super-SAG candidate includes a desktop knowledge base, file management, indexing, search, Q&A, settings and CLI. It has not been released; Windows installation, business workflows and data-preserving upgrade still require hands-on acceptance.

No installer or independent signed update channel has been published. See [Installation](/en/docs/installation) for build and verification guidance.
