## v0.1.0

Super-SAG includes a desktop knowledge base, file management, indexing, search, Q&A, settings and CLI. A [Windows installer is published](https://github.com/CalmBuilder/Super-SAG/releases/tag/v0.1.0); complete business workflows and data-preserving upgrade still require acceptance. The macOS personal edition is under verification and no macOS installer has been published.

There is no independent signed update channel yet. See [Installation](/en/docs/installation) for build and verification guidance.
