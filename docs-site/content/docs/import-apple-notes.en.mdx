---
title: "Apple Notes"
description: "Import Apple Notes downloaded to your Mac."
---

Notes is Apple’s app for writing notes, creating checklists, and saving attachments. [Apple Notes user guide](https://support.apple.com/guide/notes/welcome/mac)

1. In Super-SAG on macOS, [open Data sources](/en/docs/data-sources#open-data-sources) and choose **Import notes** next to **Apple Notes**.
2. Select the folders to import, check the destination, and click **Import**. Unlock any locked notes in the Notes app first.


If Super-SAG asks for access, choose **Open System Settings** and enable the current Super-SAG app under **Privacy & Security → Full Disk Access**. Return to Super-SAG and choose **Check again** if needed. You can also use **Choose data folder** to import a copy that contains `NoteStore.sqlite` and its attachment directories.
