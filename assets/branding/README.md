# Super-SAG 品牌素材

这里保存用户已确认的 Super-SAG 标识素材：

- [`super-sag-icon.svg`](super-sag-icon.svg)：可编辑矢量源；抽象书页形成 S，节点表示知识连接。
- [`super-sag-icon.png`](super-sag-icon.png)：已有设计的 PNG 图形素材。
- [`super-sag-logo-concept-v1.png`](super-sag-logo-concept-v1.png)：设计参考图。

深蓝 `#182B5C`、浅色 `#F8FAFF` 和青绿色 `#64DED1` 是素材使用色。桌面共享界面及 Windows 安装配置已接入此图形和名称；`src-tauri/icons/super-sag/` 的 PNG、ICO、ICNS 由此 SVG 使用锁定版本的 Tauri CLI 生成。浏览器测试使用虚构数据；实际 Windows 安装包和图标仍待实机验收。
