# Contributing to Super-SAG

Create a focused branch from `main`, preserve existing user data and compatibility, and describe the problem and validation in the change. The current application version is `0.1.0`.

For changes to user-facing behavior, update both Chinese and English documentation in `docs-site/content/docs/`. Run the relevant automated tests and `npm --prefix docs-site run build`; native Windows changes also need real Windows acceptance. Do not publish installers or configure a release channel without an explicit release instruction.
